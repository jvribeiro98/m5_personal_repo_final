M5 Personal

Grave a versão mais recente no M5StickC Plus 2 sem Arduino IDE.

  1. Use Chrome ou Edge no computador.
  2. Conecte o M5 pelo USB.
  3. Clique em Conectar e instalar.
Este navegador não suporta gravação serial. Use Chrome ou Edge.
O firmware é compilado automaticamente a partir da branch main.
